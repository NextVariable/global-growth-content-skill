# How do I find orders missing from a payment CSV?

Use the order ID to compare your order CSV with your payment CSV. An order present in the order file but absent from the payment file is a candidate for review; it is not automatically proof that the customer has not paid.

Export the two files for the same period and confirm which column holds the order ID in each. Check that IDs are represented consistently, including leading zeros and stray spaces, and review missing or duplicate IDs before relying on the comparison. These are preparation checks, not automatic correction features in ReconcilePad.

ReconcilePad aligns two CSVs by order ID, flags missing rows, and exports a list for manual review. Review orders that have no matching payment row against the original records. A difference could reflect file coverage, timing or an identifier problem, so record what you checked before treating it as an unpaid order.

The tool does not process refunds or connect to a bank. It cannot establish a bank balance or complete reconciliation on its own. For a Canadian small ecommerce bookkeeping firm, start by checking whether the exported review list fits your existing month-end process.
