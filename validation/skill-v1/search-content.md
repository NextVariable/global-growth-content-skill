**Title:** How to find orders missing from a payment CSV

**Description:** Compare order IDs in your order and payment CSVs, identify missing records and build a review list without treating missing rows as proof of non-payment.

# How do I find orders missing from a payment CSV?

Compare the order IDs in an order export with the order IDs in your payment export. An order ID that appears in the order file but not in the payment file belongs on a review list. A missing record is not proof that the customer has not paid: export dates, payment timing and the way your files represent orders may affect the comparison.

Start with exports for the period you need to check. Keep the original files and confirm which column contains the order ID in each file. Check how IDs are represented, including leading zeros, spaces, blank IDs and repeated IDs. Correct an export problem at its source or document any preparation you perform; do not assume a matching tool will repair it.

ReconcilePad can align two CSVs by order ID, flag missing rows and export a list for checking. Use the exported list to inspect the original order and payment records. It does not process refunds or connect to a bank, so resolve refund cases and payment-status questions in your existing process. Field compatibility, duplicate handling and exact output labels need verification with your data before relying on the result.

If you already have a dependable spreadsheet comparison, keep it while assessing this workflow. The question is whether a focused review list fits your bookkeeping task, not whether you must replace your spreadsheet.
