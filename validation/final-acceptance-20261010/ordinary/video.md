# 35-second English short video

**Audience and purpose:** Independent developers and small product teams using a Skill-capable agent client, with existing product facts and a target-reader decision. Show how to understand the package and begin one homepage-hero task. The example product is Global Positioning & Growth Content itself. The CTA is learning and first use through the real README.

**Format:** 35 seconds, screen recording with voiceover, readable captions and a final repository link. Record a real browser, file view and supported agent client. No actor, studio, customer footage or finished video asset is assumed.

## 0:00–0:05 — Open the real entry point

**Camera/screen action:** In a browser, open `https://github.com/NextVariable/global-growth-content-skill#readme`. Frame the repository name and the start of the README. Use the public page as it exists during filming; do not replace it with a mock page announcing unpublished features.

**Voiceover:** “A product brief can become a clearer first screen.”

**Caption:** “Global Positioning & Growth Content”

**Small subtitle:** “A Markdown Skill”

## 0:05–0:10 — Show the installation unit

**Camera/screen action:** Open `skills/global-growth-content` in the repository file browser or the obtained local package. Show `SKILL.md` and the reference, template, agent and license entries. If using a local file view, crop out personal paths and account details. Cut to the client's actual available-Skill interface with `global-growth-content` visible, but only after real discovery has been confirmed.

**Voiceover:** “This Markdown Skill works in a client that supports Skills.”

**Caption:** “Get the full package. Confirm client discovery.”

**Small subtitle:** “Your client supplies the model.”

## 0:10–0:15 — Open the authorized brief

**Camera/screen action:** Open a project document named `product-brief.md`, stored outside the installed Skill package. Select the lines for product, target reader and workflow. Use only the authorized facts below; keep the selection readable.

```text
Product: Global Positioning & Growth Content
Reader: Developers and small teams with existing product facts
Goal: Explain this Skill's workflow in one English homepage hero
Workflow: Product brief → agent drafts content → user checks claims
Evidence: Markdown package, content scope, MIT license
No customer, time-saving or conversion-result data
```

**Voiceover:** “Bring your target reader, product workflow, evidence and goal.”

**Caption:** “Existing audience + facts + one page goal”

## 0:15–0:21 — Invoke the Skill in the real client

**Camera/screen action:** Attach or paste the brief through the client's supported mechanism. Paste and send the prompt below. Hold on the identifier and the specific hero task. Cut across the genuine model wait; do not compress the waiting time into a speed claim.

```text
Use $global-growth-content with this authorized brief and existing
reader decision. Write one complete English homepage hero explaining
this Skill's workflow. Include a real README CTA and visible client/model
conditions. Flag unsupported claims separately. Do not publish anything.
```

**Voiceover:** “Ask for one complete English homepage hero. Then check the claims.”

**Caption:** “Use $global-growth-content”

**Brief cut label:** “Model wait omitted”

## 0:21–0:29 — Review an actual result

**Camera/screen action:** Show the actual output from the filmed invocation. Select a supported category/workflow claim and compare it with the brief in a split view. Show the actual client/model condition and README CTA if present. If the output contains an unsupported effect promise, request its removal and record that correction; mark any skipped wait. Capture review notes in a project file named `hero-review.md`.

**Voiceover:** “Keep supported capability claims. Remove invented results. This drafts content; it does not publish or prove conversion gains.”

**Caption:** “Check against the brief before use.”

**Small subtitle:** “Draft ≠ verified business result”

**Filming condition:** If a usable output requires more correction than fits this segment, perform the correction before recording the final review shot and label it “After review.” Do not silently show separately authored copy as the client's first output.

## 0:29–0:35 — Return to the README

**Camera/screen action:** Cut back to the real README. Hold a simple end card with the product name, CTA and exact repository URL. Include the clickable README link in the post description; the end card alone cannot provide a click target.

**Voiceover:** “Read the README, get the Skill and try your first hero.”

**Caption / end-card CTA:** “Read the README. Try one homepage hero.”

**End-card link:** `github.com/NextVariable/global-growth-content-skill`

**Visible condition:** “Requires a Skill-capable client and its model access.”
