# 35-second English demo script

**Audience:** Independent developers and small product teams with an existing target reader and product brief, using a Skill-compatible agent.

**Situation and purpose:** Show how a brief enters the Skill, becomes a hero draft, and receives a claim check. Invite understanding and a first task through the real repository README. This is an authored production script; no video, screenshot or client run is supplied.

**Format:** 9:16 screen recording with readable cropped text and English captions. Use a real client that has discovered the Skill. Prepare the complete installation unit before recording. If discovery is not confirmed, record setup troubleshooting separately rather than showing a successful Skill run.

## Shot 1 — 00:00–00:05 — Hook

**Record:** Open a text editor showing the prepared product-brief.txt excerpt below. Highlight “Goal: explain this Skill and help a developer try one hero.” The desktop frame contains only the authorized demonstration files; crop personal folders and account information.

**Voiceover:** “You have the product facts. Does your first screen explain the workflow?”

**On-screen subtitle:** “Product facts → a first screen readers can understand”

## Shot 2 — 00:05–00:10 — Product and prerequisite

**Record:** Open the already installed global-growth-content folder and its SKILL.md in a file editor. Show the title briefly, then switch to the client’s actual Skill discovery view. Show this view only if it really lists the Skill; do not fabricate an interface or success state.

**Voiceover:** “Global Positioning and Growth Content is a Markdown Skill inside your compatible agent.”

**On-screen subtitle:** “Markdown Skill · your client provides model access”

## Shot 3 — 00:10–00:16 — Input and task

**Record:** In the real client, paste the prepared first-task request and the brief. Crop to show $global-growth-content, “one English homepage hero” and the start of the product facts. Send once. Do not show unrelated conversations.

**Voiceover:** “Give it your reader, workflow, evidence and goal. Ask for one English homepage hero.”

**On-screen subtitle:** “Fixed reader + product brief + evidence + one goal”

## Shot 4 — 00:16–00:24 — Draft and check

**Record:** Jump-cut over actual response time, with “Response wait omitted” visible for the transition. Use the actual generated draft after it completes. Select the headline, then move to the claim map. Compare “Markdown Skill” against the prepared P1 fact in the editor. If the draft adds an unsupported claim, show its real correction rather than substituting a fake successful result.

**Voiceover:** “Check the draft against those facts. Remove invented outcomes, and make sure the next step leads somewhere real.”

**On-screen subtitle:** “Review capabilities, claims and the CTA”

## Shot 5 — 00:24–00:30 — Scope

**Record:** Save the reviewed draft as hero-draft.md outside the installed Skill folder. Show its headline and prerequisite line, then add a visible “Draft for review” annotation in the edit. This is a file save, not publication.

**Voiceover:** “This drafts content. Your team reviews it before publishing. It doesn’t prove conversion gains.”

**On-screen subtitle:** “Content draft · human review · publishing is a separate action”

## Shot 6 — 00:30–00:35 — Understanding and first-use CTA

**Record:** End on a typeset card with the full repository URL and “README → complete Skill unit → first hero task”. No browsing or publishing is needed to render this end card.

**Voiceover:** “Read the GitHub README, install the complete Skill, and try one hero task.”

**On-screen subtitle:** “Start with the README. Try one reviewed hero.”

**End card:**

Global Positioning & Growth Content

github.com/NextVariable/global-growth-content-skill

MIT · Skill-compatible client and model access required

## Prepared text to record

Create product-brief.txt outside the installed methods folder with this authorized example:

```text
Product: Global Positioning & Growth Content.
Reader: independent developers and small product teams with an existing
reader and product facts, using a Skill-compatible agent.
Goal: explain this Skill and help a developer try one hero.
Workflow: brief and evidence -> Skill methods -> agent draft -> human review.
P1: Markdown methods Skill for positioning and English product content.
P2: Independent 10-file unit; host client provides model access.
P3: Drafting only; no publishing, outreach, ads, sales or experiments.
P4: 2026-10-10 isolated copy and source/link checks found no errors;
all-client discovery and writing outcomes were not verified.
P5: Copy the complete skills/global-growth-content directory to the
configured client Skill root; preserve an existing installation.
P6: $global-growth-content can handle just one hero task.
P7: MIT. No customer, timing, conversion or model-quality results supplied.
CTA: https://github.com/NextVariable/global-growth-content-skill
Setup: https://github.com/NextVariable/global-growth-content-skill/blob/main/README.md
```

Paste this request above the brief in the client:

```text
Use $global-growth-content to write one complete English homepage hero
from the brief below. Keep the given reader and facts. Include headline,
subheading, real CTA and prerequisites. Separately map claims to P1–P7
and flag unsupported assumptions. Do not publish.
```
