## X technical thread — 10 posts

### Post 1

Your product brief can be accurate while your homepage is still hard to understand. Try one bounded task: turn the existing reader, workflow and evidence into a first screen you can check.

### Post 2

Global Positioning & Growth Content is a Markdown Skill for that content work. It runs through your Skill-compatible agent; your client provides model access. The repository contains methods, not a hosted website editor.

### Post 3

Get the complete skills/global-growth-content directory. It contains 10 files: SKILL.md, 6 references, a handoff template, agent metadata and LICENSE. Copy the full unit to your client’s configured Skill root; preserve any existing same-name installation.

### Post 4

Then check discovery. Seeing files in a directory is not the same as seeing the Skill in your agent. A 2026-10-10 isolated copy passed entry/link checks; automatic discovery in every client was not verified.

### Post 5

Your first input: product facts, fixed reader, workflow, evidence and a goal. No separate upstream Skill is required. Keep ongoing customer materials outside the installed methods and provide only authorized context.

### Post 6

First request: “Use $global-growth-content to rewrite our English homepage hero. Keep this reader and these facts. Return a headline, subheading, real CTA and prerequisites. Separately map claims to evidence. Do not publish.”

### Post 7

Review the draft: can a new reader identify the product, understand the workflow and find a real next step? For this Skill, “brief → methods → agent draft → human check” is supported. “Guaranteed conversion improvement” is not.

### Post 8

No performance data? Write from capabilities. Remove invented speed gains, customer counts and testimonials. Package validation proves a package check; drafting copy does not prove demand. A normal prompt may still suit a simple rewrite.

### Post 9

If discovery fails, check the client’s Skill root and complete directory. If model access fails, resolve it in the host client. If copy invents results, ask for a revision limited to your evidence. These are different failure modes.

### Post 10

Start with one reviewed hero. Global Positioning & Growth Content is MIT licensed; it drafts content and does not perform publishing, outreach, sales or experiments. Setup and the first-task entry:
https://github.com/NextVariable/global-growth-content-skill
