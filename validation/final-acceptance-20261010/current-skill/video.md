# 35-second short video — complete English production script

The viewer is an independent developer or small product team that already has product facts and uses a Skill-capable agent client. The video’s job is to make the first task understandable: put an authorized brief into the client, invoke this Markdown Skill, receive a real draft, and check its claims. It ends with the existing README as the learn/first-use entry point. This is an introduction and demonstration script, not a creator testimonial.

## 0:00–0:05 — Identify the product and starting condition

**Screen action:** Show the actual `SKILL.md` for Global Positioning & Growth Content in a file viewer. Frame the name and opening description. The operator has already obtained the complete directory; do not suggest that opening one file installed it.

**Voiceover:** “Have product facts but need an introduction? Start with this Markdown Skill.”

**On-screen text:** “Global Positioning & Growth Content” and “For a Skill-capable agent client.”

**Capture condition:** Use the authorized installation unit. Hide personal paths, account information and unrelated files. This is a real file view, not a fabricated app interface.

## 0:05–0:11 — Show the required brief

**Screen action:** In the actual client, show the prepared self-product brief from the tutorial. Slowly highlight “Reader,” “Workflow,” and “Evidence.” The text is already entered for filming; no live typing marathon is required.

**Voiceover:** “Bring your audience, workflow, evidence, and the goal of this draft.”

**On-screen text:** “Example: write this Skill’s homepage hero” and “Your client supplies model access.”

**Capture condition:** The brief must describe this Skill and include the working audience assumption and prohibited outcome claims. Use only authorized material. Do not imply automatic product import.

## 0:11–0:17 — Invoke and actually send the task

**Screen action:** Show the prepared request: “Use $global-growth-content. Write one English homepage hero from this brief. Add an internal source note.” Select the Skill by the client’s supported method if needed. Perform the actual send action, then show that the request is in the conversation.

**Voiceover:** “Ask for one homepage hero. Select the Skill, then send the request.”

**On-screen text:** “One task: homepage hero” and “Use your client’s Skill-loading method.”

**Capture condition:** Confirm the real client has loaded the Skill before recording. Do not invent a button name or load-success indicator. This shot must include the send action; a filled composer alone is insufficient.

## 0:17–0:23 — Show a real returned draft

**Screen action:** Cut to the actual completed response in the same client run. Show the headline and one short body paragraph explaining what the Skill is. Retain “Jump cut: generation wait omitted” throughout the cut into the result. If the real response is incomplete, complete or correct it before capturing; do not substitute fabricated output.

**Voiceover:** “After the wait, inspect the complete draft against the facts you supplied.”

**On-screen text:** “Jump cut: generation wait omitted” and “Example draft · review required.”

**Capture condition:** Generation has no promised duration. The result must come from the recorded task. If no compatible-client run has been completed, this shot remains unrecorded and the video cannot be described as a finished demo.

## 0:23–0:29 — Make the review visible

**Screen action:** In the response, highlight the category “Markdown Skill,” then the condition “Skill-capable client,” then the actual README link. Show a small authored overlay: “Facts ✓ · Conditions ✓ · Real next step ✓.” Use those checks only after the recorded response actually meets them.

**Voiceover:** “Check the category, the client requirement, and a real next step before use.”

**On-screen text:** “Drafting only” and “No automatic publication.”

**Capture condition:** These are content checks, not performance ratings. The brief has no evidence for savings percentages, testimonials or conversion gains. Remove any such generated claim before this shot.

## 0:29–0:35 — Finish with an achievable CTA

**Screen action:** Show the actual public repository README in a browser, followed by a simple end card with the repository name. Do not show an install-success state unless independently recorded. The operator may pre-open the README; its display is an entry-point view, not proof of installation.

**Voiceover:** “Read the README, get the complete files, and try one brief in your client.”

**On-screen text:** “Read the README → Try one hero task” and “github.com/NextVariable/global-growth-content-skill.”

**Caption link:** https://github.com/NextVariable/global-growth-content-skill#readme

**Capture condition:** There is no checkout, subscription or supplied model-credit offer. Display the real repository revision as recorded if a revision is shown; do not label it the latest local method.
