# Internal creative control

These openings are for the same UK urban-walking audience and the same existing 25-second video. Each opening occupies the first three seconds; the original middle and ending occupy the remaining duration. Retain the existing footage, edit timing, narrator, typography, music, Android framing and CTA after the opening. The sole expression hypothesis is whether a task question or an immediate action demonstration makes the manual save-and-later-view workflow easier to understand. No outcome advantage is asserted for either version.

The expected comprehension behaviour is that viewers describe manual place/note recording and prior online map download before offline viewing, and do not expect navigation. If an evaluation is later authorised, compare this understanding under otherwise unchanged conditions; no experiment has been run. GPX and exporting notes are omitted because they are outside the requested opening and note-export behaviour is unknown. No real-time tracking, performance effect, publication or creator recruitment is introduced.
